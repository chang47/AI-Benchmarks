# Targeted critique — v1

The bug catalog is substantially stronger, but these conflicts still need resolution before freeze:

1. **HTTP asset authorization has no viable credential path (A3, APP-13, APP-111).** Keys may travel only in the URL fragment and first WebSocket message, yet protected `<img>`/map GETs and export/import HTTP requests need a way to authenticate. A fragment never reaches those requests, and A3 forbids credentials in HTTP headers. Define an explicit same-origin HTTP session mechanism (including how it is established, cookie/CSRF policy, and revocation), or deliver protected assets through the authenticated socket and amend APP-13. Origin checking alone is not authentication.
2. **B07's accepted fixes contradict its server contract.** APP-91 says the protocol accepts numeric strings and the *server* stores and orders every value numerically. A client-only parse or display-only re-sort leaves raw numeric-string commands broken; a display sort can also diverge after reconnect or the GM's reorder. Either retain that contract and protocol-grade B07 (only server normalization/comparison is sufficient), or explicitly relax the wire contract and revise the alternative-fix list. Calling a display-only sort correct while APP-91 stands is inconsistent.
3. **The test-mode parity control cannot catch the advertised special-casing (CAT-02, TST-04, §7.4).** Parity repeats representative *no-dice* behaviours from five groups; it cannot detect a test-mode-only B10 dice fix or a test-mode-only B04/B08 browser fix. Yet the controls promise “a fix active only in test mode” gets zero and −4. Run a non-test-mode equivalent for every bug (ordinary dice assertions can check face count/range without forcing faces, and browser cases can use import setup), or narrow that control's claim and report uncovered bugs.
4. **Regression-group overlap needs a written partition, not just a green-matrix promise.** Groups named “visibility and fog,” “chat and whispers,” “damage, healing and death,” and “combat tracker” naturally exercise B01/B11, B06, B09/B05, and B03/B07 respectively. TST-06 nonetheless requires the all-bugs build to fail *only* F2P tests. Freeze a case-level map that assigns each failing-path assertion exclusively to its bug's F2P set and gives regression groups independent neighbouring cases; run the combined build to prove the partition.
5. **The predeclared scope cuts are not compatible with the current acceptance contract (APP-111, APP-72, APP-142).** “Export without images” contradicts APP-111's self-contained export, while “scene duplicate” and “public-monster-rolls toggle” are not specified core features to cut. Cutting player spell browsing removes APP-72. Replace the demotion list with actual optional scope, or explicitly require a spec, docs and test revision *before freeze* whenever a core feature is removed. Do not silently waive acceptance to hit the line count.
6. **Web-tool denial is not network isolation (§11).** Denying WebSearch/WebFetch leaves shell HTTP clients and any other tool's network path available; the public spec and patches remain retrievable. If catalog secrecy matters, test and enforce outbound egress denial in the run sandbox (including subprocesses), or label web access as an uncontrolled contamination risk rather than relying on `tools.deny`.

**Residual risk:** The three browser-graded paths and 120-minute repair target remain empirical gates, not demonstrated properties; retain the measured calibration and Windows runs before freeze.
